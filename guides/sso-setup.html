SSO Setup (SAML 2.0)

Configure Single Sign-On so your team logs in through your organization's Identity Provider.

Enterprise feature. SSO is available on the Enterprise plan. View pricing

What You'll Need

Use these values when configuring your Identity Provider:

Setting Value
SP Entity ID (Audience URI) https://walklists.com/saml/metadata
ACS URL (Single Sign-On URL) https://walklists.com/saml/acs
SLS URL (Single Logout) https://walklists.com/saml/sls
NameID Format EmailAddress
SP Metadata XML Download XML

Okta Setup

1

Create the app in Okta

Log into your Okta Admin Console. Navigate to Applications → Applications → Create App Integration. Select SAML 2.0 and click Next.

2

Configure SAML settings

Set the App name to "WalkLists". Under SAML Settings:

  • Single Sign-On URL: https://walklists.com/saml/acs
  • Audience URI (SP Entity ID): https://walklists.com/saml/metadata
  • Name ID format: EmailAddress
  • Application username: Email
3

Copy your IdP details

After saving, go to the Sign On tab and copy these three values:

  • IdP Issuer (Identity Provider Issuer)
  • IdP SSO URL (Identity Provider Single Sign-On URL)
  • X.509 Certificate (click "View SAML setup instructions")

Send these to your WalkLists administrator.

Azure AD (Entra ID) Setup

1

Create the enterprise application

In the Azure Portal, go to Microsoft Entra ID → Enterprise Applications → New application → Create your own application. Name it "WalkLists", select "Integrate any other application", and click Create.

2

Configure SAML

Go to Single sign-on → SAML. Edit Basic SAML Configuration:

  • Identifier (Entity ID): https://walklists.com/saml/metadata
  • Reply URL (ACS URL): https://walklists.com/saml/acs
3

Copy your IdP details

Under SAML Certificates, download the Certificate (Base64). Under Set up WalkLists, copy:

  • Login URL (IdP SSO URL)
  • Azure AD Identifier (IdP Entity ID)

Send the Login URL, Azure AD Identifier, and Certificate to your WalkLists administrator.

OneLogin Setup

1

Add a SAML app

In OneLogin Admin, go to Applications → Add App. Search for "SAML Custom Connector (Advanced)". Set the Display Name to "WalkLists" and click Save.

2

Configure the connector

Go to the Configuration tab:

  • ACS (Consumer) URL: https://walklists.com/saml/acs
  • Audience (EntityID): https://walklists.com/saml/metadata
3

Copy your IdP details

Go to the SSO tab and copy:

  • Issuer URL (IdP Entity ID)
  • SAML 2.0 Endpoint (HTTP) (IdP SSO URL)
  • X.509 Certificate (click "View Details" to copy)

Send these to your WalkLists administrator.

Testing & Activation

  1. Send your IdP details (Entity ID, SSO URL, X.509 Certificate) to your WalkLists administrator
  2. The admin will create your SSO provider and activate it
  3. Test with one user: go to the login page, click "Sign in with SSO", and enter your work email
  4. You'll be redirected to your Identity Provider, then back to WalkLists
  5. Once confirmed, optionally enable "Enforce SSO" to disable password login for your entire domain
Need help? Contact our support team and we'll walk you through the setup.
