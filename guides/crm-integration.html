Connect WalkLists to Your CRM

Send new contacts and door results into HubSpot, Salesforce, Google Sheets and thousands of apps — the moment they happen, not a nightly export.

WalkLists is the field layer on top of the tools you already run. There are three ways to move your door data into them, from no-code to fully custom. Most teams start with Zapier.

Before you start: create an API key

Every connection authenticates with an API key scoped to your organisation.

1

Open Account → API keys

In WalkLists, go to Account → API keys and create a key. You see it once, at creation — copy it somewhere safe. You can revoke it any time.

API access is included on the Team and Local plans and above. Real-time webhooks are included on every plan, free ones too.

Option 1 — Zapier (no code)

Connect WalkLists to 7,000+ apps — HubSpot, Salesforce, Pipedrive, Google Sheets, Slack and more — without writing any code. Build a workflow in a few clicks and it runs on its own.

Early access. The WalkLists Zapier integration works today and is available to customers now, while our public Zapier listing is being finalised. Ask us for your invite and we’ll get you connected the same day.

1

Request your invite

Tell us at walklists.com/contact and we’ll send the link that adds the WalkLists app to your Zapier account.

2

Connect your WalkLists account

In Zapier, choose WalkLists and paste the API key you created above.

3

Build a Zap

Pick a trigger — New Contact, Updated Contact or New Door Activity — and an action in your CRM. For example: New Door Activity → Create a HubSpot deal. Turn it on, and it runs on every knock.

Option 2 — Real-time webhooks

Have WalkLists POST each event to your own endpoint the instant it happens — no polling, no delay. This is the real-time backbone the other options are built on, and it’s included on every plan.

1

Add an endpoint

Go to Account → Webhooks and add the URL you want events sent to. The signing secret is shown once, at that moment.

2

Verify the signature

Each delivery is signed with HMAC-SHA256 and a timestamp. Verify it before you trust the body — anyone can POST to your URL. The full recipe is in the API reference.

WalkLists does not offer native two-way CRM sync (pushing WalkLists edits and pulling CRM edits automatically). Data flows out through webhooks and Zapier, and in through the API or a Zapier action — you choose which directions you need.

Option 3 — REST API

For custom integrations, read and write contacts, lists, campaigns and door activity directly. The API is versioned, rate-limited and documented, with a live reference and a Postman collection at walklists.com/developers/api.

See it all in the app

Everything above has a home inside WalkLists at Account → Automations — ready-made recipes, the connect steps, and a check of whether you already have an API key.

Common recipes

  • A canvasser marks a supporter → add them to your phone-bank list and send a thank-you.
  • A rep logs a hot lead → create the deal in HubSpot or Salesforce and assign the follow-up.
  • A door is marked “callback” → create a task with the time and notes in your CRM.
  • A roof is inspected → open a job in JobNimbus with the address, photos and notes.
  • A new contact is added → append a row to Google Sheets or push it to Mailchimp.
